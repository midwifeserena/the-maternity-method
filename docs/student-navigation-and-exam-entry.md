# Student navigation and exam entry

The sidebar preserves the logo/name and verified Student/Admin toggle. Student top-level links are Dashboard, Question Bank, Video Lessons, Study Guides, Flashcards, and Account & Subscription. Question Bank expands to Create Exam, NGN Case Studies, Previous Exams, and Performance. Its label opens the Question Bank page and expands the group; the chevron toggles without navigation. Direct exam-review links expand/highlight the corresponding submenu. Mobile child selection closes the drawer. Admin studios and authorization are unchanged.

Create Exam keeps Question Mode and Question Category. Category buttons support standalone questions, standalone NGN questions, complete NGN case studies, or any combination. Cases are selected automatically by subject and kept in complete six-item blocks. A single total count supports up to 150 questions after the proposed database upgrade. All use the same Exam player after the proposed combined-session database setup. The direct NGN shortcut remains while the owner decides whether to remove it; complete cases there also use the unified player when setup is ready. Previous Exams labels keep the existing /previous-tests URLs.

See docs/combined-exams.md for scoring, history, reveal rules, the proposed migration, backward-compatible readiness behavior, and verification. Combining content requires the proposed SQL; no production SQL or deployment was performed. Existing standalone exams and direct case practice remain available before that setup is installed.
